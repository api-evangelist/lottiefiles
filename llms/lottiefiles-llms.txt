# LottieFiles

> LottieFiles is the platform, tooling, and open runtime ecosystem for Lottie and dotLottie animations — a lightweight, JSON-based animation format that ships vector motion on any platform as easily as a static asset. LottieFiles' developer surface is a family of first-party, open-source "dotLottie" players (Rust + WASM core) and framework/native components rather than a hosted HTTP API; developers integrate by installing a runtime and rendering animations client-side.
